# Media for Gasworks

Drop finalized assets here (see **PLACEHOLDERS.md** in the parent folder for sizes and filenames).

Suggested names:

- `hero-poster.jpg` / `hero-reel.mp4`
- `work-01.jpg` … `work-06.jpg`
- `services-still.jpg`
- `about-portrait.jpg`
- `clients/*.svg` (optional subfolder)

Git does not track large binaries unless you commit them; for big videos consider hosting on Vimeo/YouTube and embedding instead.

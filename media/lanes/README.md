# Capability lane reels

One loop per lane (16:9, muted, no audio). Drop files at:

| Lane | File |
|------|------|
| Commercial | `commercial.mp4` + `commercial-poster.jpg` |
| Narrative | `narrative.mp4` + `narrative-poster.jpg` |
| Documentary | `documentary.mp4` + `documentary-poster.jpg` |
| Live-Event | `live-event.mp4` + `live-event-poster.jpg` |

Replace each `.lanes__placeholder` block in `index.html` with a `.lanes__media-fill` wrapper containing `<video>` or `<img>`.

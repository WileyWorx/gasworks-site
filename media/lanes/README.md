# Capability lane reels

One loop per lane (16:9, muted, no audio). Drop files at:

| Lane | File |
|------|------|
| Spotlights | `spotlights.mp4` + `spotlights-poster.jpg` |
| Narratives | `narratives.mp4` + `narratives-poster.jpg` |
| Immersions | `immersions.mp4` + `immersions-poster.jpg` |

Replace each `.lanes__placeholder` block in `index.html` with a `.lanes__media-fill` wrapper containing `<video>` (see the Narratives lane for the pattern).

Recommended export: **1920×1080** MP4 (H.264), 4–12 s loop, `faststart` for web. Keep subject **center to center-right** — copy sits on the left.
